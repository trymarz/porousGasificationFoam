# Plan: Add YADE Pre-Compaction Phase Before Starting Coupled CFD-DEM

## Context

When `porousGasificationFoam` starts, YADE and OpenFOAM couple from iteration zero. But the sphere packing has small gaps from the grid-based placement — spheres free-fall under gravity while chemistry/hydrodynamics are already active. This creates unphysical startup transients (freefall through fluid, spurious drag, continuity spikes).

The user wants: (1) YADE runs alone with gravity to settle the bed, (2) settled positions saved, (3) then the coupled run starts from the settled state.

### Why we can't just call `O.run()` before `mp.mpirun()`

YADE's MPI engines (`GlobalStiffnessTimeStepper`, `InsertionSortCollider`) try to sync across MPI ranks. Before `mp.mpirun()` calls `splitScene()`, this synchronization blocks. The updraftDemo `MPI_lambda.py` has an explicit comment: *"O.run() settling is NOT viable in MPI mode"*.

### Approach: standalone single-process YADE compaction

Run `yade compact.py` as a **single-process, non-MPI** YADE simulation before the coupled run. This script creates the identical sphere packing, runs gravity-only DEM until the bed settles, and writes the final positions to `compact_positions.txt`. Then `MPI_lambda.py` reads those positions instead of computing fresh grid positions.

Key insight: **sphere creation order is deterministic** — `compact.py` and `MPI_lambda.py` use identical nested loops, so YADE body IDs match between the two. No ID remapping needed.

## Approach

### Step 1: Create `compact.py`

This is a self-contained YADE script (no MPI, no FoamCoupling).

**Contents:**

```python
# compact.py — Gravity-only DEM compaction for posterDemo-layers.
# Run once before the coupled CFD-DEM simulation.
#
# Creates the same sphere packing as MPI_lambda.py, lets the bed
# settle under gravity in single-process (non-MPI) YADE, then saves
# the settled positions to compact_positions.txt.
#
# Usage:  yade compact.py

import math

# ── geometry parameters (must match MPI_lambda.py) ──
radius           = 0.003        # m
y_positions      = [0.004, 0.01]  # m

# Domain (must match blockMeshDict)
lx = 0.04
lz = 0.096

# Derived spacing
step    = 2.0 * radius               # 0.006
dz      = radius * math.sqrt(3.0)    # 0.005196

# Sphere counts per row/layer
nx_even = int((lx - 2*radius) / step) + 1   # 6
nx_odd  = int((lx - 3*radius) / step) + 1   # 6
nz      = int((lz - 2*radius) / dz) + 1     # 18

z_start = radius

# ── material ──
m_id = O.materials.append(FrictMat(young=1e6, poisson=0.3, frictionAngle=0.5, density=500))

# ── walls (must match MPI_lambda.py) ──
O.bodies.append(box(center=(lx/2, 0.009, lz/2), extents=(lx/2 + 0.01, 0.009, lz/2 + 0.01),
                    fixed=True, material=m_id))

# ── sphere packing — EXACT same order as MPI_lambda.py ──
spheres = []
for y_pos in y_positions:
    for k in range(nz):
        x0  = radius + (k % 2) * radius
        for i in range(nx_even - (k % 2)):
            z = z_start + k * dz
            x = x0 + i * step
            sp = sphere((x, y_pos, z), radius, material=m_id)
            sp.state.blockedDOFs = 'zXy'  # prevent rotation (match MPI_lambda.py)
            spheres.append(sp)

nsp = len(spheres)
print(f"[compact] Created {nsp} spheres (expect 216)")

# ── DEM engine (gravity only, no FoamCoupling) ──
O.engines = [
    ForceResetter(),
    InsertionSortCollider([Bo1_Sphere_Aabb(), Bo1_Box_Aabb()]),
    InteractionLoop(
        [Ig2_Sphere_Sphere_ScGeom(), Ig2_Box_Sphere_ScGeom()],
        [Ip2_FrictMat_FrictMat_FrictPhys()],
        [Law2_ScGeom_FrictPhys_CundallStrack()]
    ),
    GlobalStiffnessTimeStepper(),
    NewtonIntegrator(gravity=(0, 0, -9.81), damping=0.4)
]

O.dt = 1e-6  # initial estimate; GlobalStiffnessTimeStepper adjusts

# ── settling loop ──
# Run until kinetic energy drops, then run a fixed period more
settleTarget = 1.0   # simulate 1.0 s virtual time for thorough settling
print(f"[compact] Settling for {settleTarget} s...")
O.run(int(settleTarget / O.dt), wait=True)

# Brief additional run to confirm stillness
if O.time < settleTarget:
    O.run(int((settleTarget - O.time) / O.dt), True)

print(f"[compact] Done at t = {O.time:.4f} s, {O.iter} iterations")

# ── save final positions ──
with open("compact_positions.txt", "w") as f:
    for sp in spheres:
        pos = sp.state.pos
        f.write(f"{pos[0]:.10e} {pos[1]:.10e} {pos[2]:.10e}\n")

print(f"[compact] Saved {len(spheres)} sphere positions to compact_positions.txt")
```

**Verification:** Run `yade compact.py` and check that `compact_positions.txt` has exactly 216 lines.

### Step 2: Modify `MPI_lambda.py` — load compacted positions

In the sphere creation section (currently lines 48-91), add logic to load from `compact_positions.txt` if it exists.

**Replace the sphere packing block** with:

```python
# ── geometry domain ──
lx = 0.04
lz = 0.096

compact_file = os.path.join(os.path.dirname(__file__), "compact_positions.txt")

if os.path.exists(compact_file):
    # ── load compacted positions from pre-compaction run ──
    print(f"[YADE] Loading compacted sphere positions from {compact_file}")
    positions = []
    with open(compact_file, "r") as f:
        for line in f:
            parts = line.strip().split()
            positions.append((float(parts[0]), float(parts[1]), float(parts[2])))
    print(f"[YADE] Read {len(positions)} positions")

    for (x, y, z) in positions:
        sp = sphere((x, y, z), radius, material=m_id)
        sp.state.blockedDOFs = 'zXy'
        spheres.append(sp)

else:
    # ── compute fresh grid packing (original logic) ──
    step    = 2.0 * radius
    dz      = radius * math.sqrt(3.0)
    nx_even = int((lx - 2*radius) / step) + 1
    nx_odd  = int((lx - 3*radius) / step) + 1
    nz      = int((lz - 2*radius) / dz) + 1
    z_start = radius

    for y_pos in y_positions:
        for k in range(nz):
            x0  = radius + (k % 2) * radius
            for i in range(nx_even - (k % 2)):
                z = z_start + k * dz
                x = x0 + i * step
                sp = sphere((x, y_pos, z), radius, material=m_id)
                sp.state.blockedDOFs = 'zXy'
                spheres.append(sp)

numSpheres = len(spheres)
nlayers_y = len(y_positions)
if os.path.exists(compact_file):
    print(f"[YADE] Created {numSpheres} spheres from compacted positions")
else:
    print(f"[YADE] Created {numSpheres} spheres in {nz} z-layers × {nlayers_y} y-layers, "
          f"z range [{z_start:.4f}, {z_start + (nz-1)*dz:.4f}], "
          f"y positions: {y_positions}, "
          f"rows: {nx_even}/{nx_odd}")
```

## Verification

1. **compact.py runs standalone:** `yade compact.py` produces `compact_positions.txt` with 216 lines, positions that differ from the original grid (settled coordinates).

2. **MPI_lambda.py loads correctly:** When `compact_positions.txt` is present, the log header shows `"Created 216 spheres from compacted positions"` instead of the grid-coordinate message.

3. **No ID mismatch:** Both scripts create spheres in identical order, so YADE body IDs and `sphereIDs` list match. `FoamCoupling::setIdList()` receives the same IDs it expects.

4. **Coupled run starts from settled state:** When the coupled simulation begins, spheres should not free-fall — kinetic energy should remain near zero at t=0, and the continuity error should start lower (no spurious displacement of fluid by falling spheres).

5. **Full workflow:** `./Allclean && ./Allrun` should proceed without errors.

6. **Regeneration:** Running `./Allclean` removes `compact_positions.txt`. Running `./Allrun` recreates it by running compact.py first, then proceeds to the coupled run. Manual re-compaction (e.g., after changing radius or chemistry): `rm compact_positions.txt && yade compact.py`.
